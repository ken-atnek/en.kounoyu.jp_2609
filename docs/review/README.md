# レビュー記録

レビューの共通仕様とテンプレートは、React / Next.js共通プレイブックの `workflow.md` と `review.md` を正とします。

このディレクトリには、英語版LPのレビュー結果と対応状況を日付別に保存します。

## ファイル名

- 通常レビュー: `REVIEW_YYYY-MM-DD.md`
- 外部レビュー依頼: `REVIEW_REQUEST_YYYY-MM-DD.md`
- 外部レビュー原文: `EXTERNAL_REVIEW_ツール名_YYYY-MM-DD.md`
- 修正トラッカー: `REVIEW_FIX_TRACKER_YYYY-MM-DD.md`

同じ日付・種類のファイルがある場合は、`_02`、`_03`のように連番を付け、上書きしません。

## 英語版LPで確認すること

- PCデザインとの一致
- SP表示での破綻と未確定事項
- LP内アンカーとキーボード操作
- Next.js 16と静的書き出しの整合
- デモ・本番サブドメイン直下のasset pathと内部リンク
- 英語の施設名、客室名、温泉名、地名の表記
- canonical、hreflang、robots、sitemap
- 予約、交通機関、Google Maps、周辺施設の外部リンク
- 画像alt、OGP画像、構造化データ
- 公開サーバーでのみ確認できる項目

## 記録ルール

- 冒頭に進捗サマリーを置く
- 対象ファイル、対応内容、確認方法、結果、残タスクを記載する
- 静的チェック済みと、実機・ビルド・公開後の再確認を分ける
- 共有用Markdownにマシン固有の絶対パスを残さない
