# 英語版データ連携方針

クライアントデータ取得の一般的な実装は、React / Next.js共通プレイブックの `patterns.md` と `nextjs-static-export.md` を参照します。

## 現在の状態

- 英語版が `public/db/` のJSONを利用するか未確定
- 管理画面との連携範囲は未確認
- JSONスキーマと型定義は未作成
- データ取得方法を実装済み仕様として固定しない

## 採用前に確認すること

- 日本語版と英語版で共有するデータ
- 英語専用で管理するデータ
- 管理画面が書き換えるファイルとタイミング
- ビルド後の更新反映が必要なデータ
- 画像、予約情報、料金、営業時間などの管理元
- 公開サーバーのCache-Control
- デモ環境と本番環境のJSONパス

## `public/db/`を採用する場合

- ビルド後更新が必要なJSONはClient Componentから取得する
- サブドメイン直下のURLとして取得パスを組み立てる
- 読み込み中、空データ、取得失敗を区別する
- キャッシュ回避は公開サーバーの挙動を確認して決める
- 複数JSONの取得・結合が必要な場合は、用途が分かるカスタムhookへ閉じ込める
- JSON型は実際のスキーマ確定後、共通の型定義ファイルで管理する

## 案件側に記録する内容

採用が確定したら、このファイルへ次を追記します。

- JSONファイル一覧
- 各ファイルの管理元
- 日本語版との共有・分離方針
- TypeScript型の配置
- fallback値
- エラー表示
- キャッシュ制御
- 更新確認方法

採用しない場合は、このファイルを削除候補とします。
